В языке C есть функция `printf`. Она позволяет выводить что-либо с форматированием. Например:

```c
printf("The result is %d.", 42);
```

В этой задаче нужно разобрать входную строку и извлечь из неё спецификаторы формата, такие как `%d` и `%f`. Например, для входной строки `"The result is %d."` результатом будет кортеж `['dec']`.

Вот соответствие:

```typescript
type ControlsMap = {
  c: 'char',
  s: 'string',
  d: 'dec',
  o: 'oct',
  h: 'hex',
  f: 'float',
  p: 'pointer',
}
```
