> Для этой задачи рекомендуется TypeScript 4.0

Реализуйте generic `Pop<T>`, который принимает массив `T` и возвращает массив без последнего элемента.

Например:

```ts
type arr1 = ['a', 'b', 'c', 'd']
type arr2 = [3, 2, 1]

type re1 = Pop<arr1> // ожидается ['a', 'b', 'c']
type re2 = Pop<arr2> // ожидается [3, 2]
```

**Дополнительно**: можете ли вы аналогично реализовать `Shift`, `Push` и `Unshift`?
