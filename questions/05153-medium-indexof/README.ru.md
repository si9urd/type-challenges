Реализуйте типовую версию Array.indexOf. `IndexOf<T, U>` принимает массив T и любой U и возвращает индекс первого U в массиве T.

```ts
type Res = IndexOf<[1, 2, 3], 2>; // ожидается 1
type Res1 = IndexOf<[2,6, 3,8,4,1,7, 3,9], 3>; // ожидается 2
type Res2 = IndexOf<[0, 0, 0], 2>; // ожидается -1
```
