Реализуйте продвинутый утилитный тип MutableKeys<T>, который собирает все изменяемые (не readonly) ключи в объединение (union).

Например:

```ts
type Keys = MutableKeys<{ readonly foo: string; bar: number }>;
// ожидается “bar”
```
