Реализуйте `StartsWith<T, U>`, который принимает два точных строковых типа и возвращает, начинается ли `T` с `U`.

Например:

```typescript
type a = StartsWith<'abc', 'ac'> // ожидается false
type b = StartsWith<'abc', 'ab'> // ожидается true
type c = StartsWith<'abc', 'abcd'> // ожидается false
```
