Дан массив уникальных элементов; верните все возможные подпоследовательности.

Подпоследовательность — это последовательность, которую можно получить из массива, удалив некоторые элементы (или ни одного) без изменения порядка остальных элементов.

Например:

```typescript
type A = Subsequence<[1, 2]> // [] | [1] | [2] | [1, 2]
```
