Для заданного кортежа создайте generic `Length`, который получает длину этого кортежа.

Например:

```ts
type tesla = ['tesla', 'model 3', 'model X', 'model Y']
type spaceX = ['FALCON 9', 'FALCON HEAVY', 'DRAGON', 'STARSHIP', 'HUMAN SPACEFLIGHT']

type teslaLength = Length<tesla>  // ожидается 4
type spaceXLength = Length<spaceX> // ожидается 5
```
