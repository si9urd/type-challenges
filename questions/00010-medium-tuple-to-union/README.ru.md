Реализуйте generic `TupleToUnion<T>`, который превращает значения кортежа в объединение (union) этих значений.

Например:

```ts
type Arr = ['1', '2', '3']

type Test = TupleToUnion<Arr> // ожидается '1' | '2' | '3'
```
