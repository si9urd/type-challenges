Дан массив строк; выполните перестановки и комбинации.
Это полезно и для типов props, например у видео — [controlsList](https://developer.mozilla.org/ru/docs/Web/API/HTMLMediaElement/controlsList).

```ts
// ожидается `"foo" | "bar" | "baz" | "foo bar" | "foo bar baz" | "foo baz" | "foo baz bar" | "bar foo" | "bar foo baz" | "bar baz" | "bar baz foo" | "baz foo" | "baz foo bar" | "baz bar" | "baz bar foo"`
type Keys = Combination<['foo', 'bar', 'baz']>
```
