Нужно реализовать частичный парсер на уровне типов, который разбирает JSON-строку в объектный литеральный тип.

Требования:
 - `Числа` и `Unicode-экранирование (\uxxxx)` в JSON можно игнорировать. Разбирать их не нужно.
