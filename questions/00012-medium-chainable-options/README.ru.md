Цепочки вызовов с опциями (chainable options) часто встречаются в JavaScript. Но можете ли вы правильно типизировать их в TypeScript?

В этой задаче нужно типизировать объект или класс (на ваш выбор), предоставляющий две функции: `option(key, value)` и `get()`. В `option` можно расширять текущий тип конфигурации переданными ключом и значением. Итоговый результат должен быть доступен через `get`.

Например:

```ts
declare const config: Chainable

const result = config
  .option('foo', 123)
  .option('name', 'type-challenges')
  .option('bar', { value: 'Hello World' })
  .get()

// ожидается, что тип result будет:
interface Result {
  foo: number
  name: string
  bar: {
    value: string
  }
}
```

Писать какую-либо js/ts-логику не нужно — только на уровне типов.

Можно считать, что `key` принимает только `string`, а `value` может быть любым — оставьте его как есть. Один и тот же `key` дважды не передаётся.
