Реализуйте PercentageParser<T extends string>.
По регулярному выражению `/^(\+|\-)?(\d*)?(\%)?$/` нужно сопоставить T и получить три совпадения.

Структура должна быть такой: [`плюс или минус`, `число`, `единица измерения`]
Если часть не найдена, по умолчанию используется пустая строка.

Например:

```ts
type PString1 = ""
type PString2 = "+85%"
type PString3 = "-85%"
type PString4 = "85%"
type PString5 = "85"

type R1 = PercentageParser<PString1> // ожидается ['', '', '']
type R2 = PercentageParser<PString2> // ожидается ["+", "85", "%"]
type R3 = PercentageParser<PString3> // ожидается ["-", "85", "%"]
type R4 = PercentageParser<PString4> // ожидается ["", "85", "%"]
type R5 = PercentageParser<PString5> // ожидается ["", "85", ""]
```
