Дан кортежный тип ```T```, содержащий только строковые типы, и тип ```U```. Рекурсивно постройте объект.

```typescript
type a = TupleToNestedObject<['a'], string> // {a: string}
type b = TupleToNestedObject<['a', 'b'], number> // {a: {b: number}}
type c = TupleToNestedObject<[], boolean> // boolean. если кортеж пуст, просто вернуть тип U
```
