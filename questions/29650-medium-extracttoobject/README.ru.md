Реализуйте тип, который выносит значение свойства в интерфейс. Тип принимает два аргумента. Результатом должен быть объект со значениями свойства.
  Значение свойства — объект.

  Например:

```ts
type Test = { id: '1', myProp: { foo: '2' }}
type Result = ExtractToObject<Test, 'myProp'> // ожидается { id: '1', foo: '2' }
```
