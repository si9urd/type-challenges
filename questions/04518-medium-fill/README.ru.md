`Fill` — распространённая функция JavaScript, давайте реализуем её на типах.
`Fill<T, N, Start?, End?>` — как видите, `Fill` принимает четыре параметра типа, из которых `T` и `N` обязательные, а `Start` и `End` необязательные.
Требования к параметрам: `T` должен быть кортежем (`tuple`), `N` может быть значением любого типа, `Start` и `End` должны быть целыми числами, большими или равными 0.

```ts
type exp = Fill<[1, 2, 3], 0> // ожидается [0, 0, 0]
```
Чтобы имитировать настоящую функцию, в тестах могут встречаться граничные условия — надеюсь, вам понравится :)
