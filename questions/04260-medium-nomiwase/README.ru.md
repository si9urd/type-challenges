Реализуйте тип ```AllCombinations<S>```, который возвращает все комбинации строк, использующие символы из ```S``` не более одного раза.

Например:

```ts
type AllCombinations_ABC = AllCombinations<'ABC'>;
// должно быть '' | 'A' | 'B' | 'C' | 'AB' | 'AC' | 'BA' | 'BC' | 'CA' | 'CB' | 'ABC' | 'ACB' | 'BAC' | 'BCA' | 'CAB' | 'CBA'
```
