Реализуйте утилитный тип `If<C, T, F>`, который принимает условие `C`, «истинное» значение `T` и «ложное» значение `F`. Ожидается, что `C` — это `true` или `false`, а `T` и `F` могут быть любыми типами.

Например:

```ts
type A = If<true, 'a', 'b'>  // ожидается 'a'
type B = If<false, 'a', 'b'> // ожидается 'b'
```
