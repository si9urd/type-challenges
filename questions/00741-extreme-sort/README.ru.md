В этой задаче нужно отсортировать массивы натуральных чисел по возрастанию или по убыванию.

Примеры сортировки по возрастанию:
```ts
Sort<[]> // []
Sort<[1]> // [1]
Sort<[2, 4, 7, 6, 6, 6, 5, 8, 9]> //  [2, 4, 5, 6, 6, 6, 7, 8, 9]
```

Тип `Sort` также должен принимать булев тип. Если он равен `true`, результат должен быть отсортирован по убыванию. Примеры:

```ts
Sort<[3, 2, 1], true> // [3, 2, 1]
Sort<[3, 2, 0, 1, 0, 0, 0], true> // [3, 2, 1, 0, 0, 0, 0]
```

Дополнительные задачи:
1. Поддержка натуральных чисел с 15+ цифрами.
2. Поддержка чисел с плавающей точкой.
