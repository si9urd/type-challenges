Реализуйте тип ```IsTuple```, который принимает входной тип ```T``` и возвращает, является ли ```T``` кортежным типом.

Например:

```typescript
type case1 = IsTuple<[number]> // true
type case2 = IsTuple<readonly [number]> // true
type case3 = IsTuple<number[]> // false
```
