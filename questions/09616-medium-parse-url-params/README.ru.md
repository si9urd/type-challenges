Нужно реализовать парсер на уровне типов, который разбирает строку параметров URL в объединение (union).

```ts
ParseUrlParams<':id'> // id
ParseUrlParams<'posts/:id'> // id
ParseUrlParams<'posts/:id/:user'> // id | user
```
