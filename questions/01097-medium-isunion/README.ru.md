Реализуйте тип `IsUnion`, который принимает входной тип `T` и возвращает, разрешается ли `T` в объединение (union).

Например:

```ts
type case1 = IsUnion<string> // false
type case2 = IsUnion<string | number> // true
type case3 = IsUnion<[string | number]> // false
```
