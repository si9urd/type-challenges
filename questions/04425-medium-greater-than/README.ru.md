В этой задаче нужно реализовать тип `GreaterThan<T, U>`, аналог `T > U`.

Отрицательные числа учитывать не нужно.

Например:

```ts
GreaterThan<2, 1> // должно быть true
GreaterThan<1, 1> // должно быть false
GreaterThan<10, 100> // должно быть false
GreaterThan<111, 11> // должно быть true
```

Удачи!
