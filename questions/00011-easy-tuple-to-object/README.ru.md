Дан массив. Преобразуйте его в объектный тип, в котором ключи и значения берутся из этого массива.

Например:

```ts
const tuple = ['tesla', 'model 3', 'model X', 'model Y'] as const

type result = TupleToObject<typeof tuple> // ожидается { 'tesla': 'tesla', 'model 3': 'model 3', 'model X': 'model X', 'model Y': 'model Y'}
```
