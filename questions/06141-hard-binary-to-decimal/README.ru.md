Реализуйте `BinaryToDecimal<S>`, который принимает точный строковый тип `S`, состоящий из 0 и 1, и возвращает точный числовой тип, соответствующий `S`, если рассматривать `S` как двоичное число.
Можно считать, что длина `S` не превышает 8 и `S` не пуста.

```ts
type Res1 = BinaryToDecimal<'10'>; // ожидается 2
type Res2 = BinaryToDecimal<'0011'>; // ожидается 3
```
